# 輔具補助指南針

幫助家屬與長輩快速了解台灣「長照 3.0」、身心障礙者輔具補助與醫療輔具補助的網站

網址：https://chennn231-code.github.io/assistive-device-compass/

## 功能

- 情境入口：幫家人辦補助、已有評估單、查某一種輔具，只顯示相關內容
- 新手引導（一次只看一步）與全覽模式切換
- 資格快篩：勾選狀況，立即顯示可能適用的補助管道
- 先申請再購買提醒、四步驟申請流程（白話說明＋對照公文用語）、應備文件清單
- 不用出門也能辦：1966、社家署輔具線上申辦、臺北市與新北市系統、進度查詢
- 補助金額試算：先選戶籍縣市，比較長照與身障兩種管道的補助額與自付額
- 長照 3 年輔具額度計算（第一組 4 萬、第二組 6 萬、居家無障礙 2 萬上限）
- 長照 3.0 智慧輔具專區與租金試算（原住民族地區、離島加計 20% 自動帶入）
- 全部輔具查詢：支援口語、症狀反查，例如「浴室會滑」「抱不動長輩」
- 居家無障礙專區：房屋平面圖逐區檢查、各縣市長照特約單位名單
- 找輔具中心和長照特約輔具店
- 給家人：懶人包卡片、複製 LINE 討論摘要、分享試算連結（資料只存在網址裡）
- 小知識庫：從長照 1.0 到 3.0，輔具與居家無障礙補助怎麼變
- 無障礙設計：字級切換、高對比模式、手機底部工具列

## 檔案

- `index.html`：整個網站（HTML、CSS、JavaScript 都在這個檔案）
- `data/ltc-ef.json`：衛福部長照服務資源地理地圖中「輔具及居家無障礙環境改善服務」特約單位名單
- `img/`：網站照片
- `tools/`：輔具清單產生腳本

## 隱私

不蒐集個人資料，勾選與設定只存在使用者自己的瀏覽器；分享連結的內容只存在網址裡，不經過伺服器
