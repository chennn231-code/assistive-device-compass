# 輔具補助指南針

幫助家屬與長輩快速了解台灣「長照 2.0」與「身心障礙者輔具補助」的單頁網站

## 功能

- 資格快篩：勾選狀況，立即顯示可能適用的補助管道（只在瀏覽器內計算，不蒐集個資）
- 先申請再購買提醒
- 補助金額試算：比較長照與身障兩種管道的補助額、自付額與使用年限
- 四步驟申請流程（白話說明＋對照公文用語）
- 公文名詞翻譯
- 無障礙設計：字級切換（標準／大／特大）、高對比模式、手機底部一鍵撥打 1966

## 檔案

- `index.html`：整個網站（HTML、CSS、JavaScript 都在這個檔案）
- `img/`：網站照片，檔名需為 `hero.jpg`、`portrait.jpg`、`svc1.jpg`、`svc2.jpg`、`svc3.jpg`；沒有放照片時會顯示灰色佔位框

## 本機預覽

直接用瀏覽器打開 `index.html` 即可
